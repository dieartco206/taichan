# Sate Taichan 56 Djoeanda — Landing Page Premium 🍢🔥

Landing page modern, cepat, dan premium untuk **Sate Taichan 56 Djoeanda**, kuliner malam hits legendaris di Jl. Margonda Raya, Depok. Seluruh data dan informasi bersumber langsung dari akun Instagram resmi [@taichan56djoeanda](https://www.instagram.com/taichan56djoeanda/) serta daftar menu resmi di Margonda.

---

## ✨ Fitur Unggulan

1. **Desain Luxury Dark Mode Foodie**: Palet arang hitam obsidian (`#07080a`), aksen nyala api (*flame orange* & *chili red*), sentuhan *fresh lime green*, serta efek *glassmorphism* modern.
2. **Animasi & Interaksi Halus (Framer Motion)**:
   - Skewer hero card dengan efek kilau panggangan (*fresh from the grill*).
   - Staggered entrance, scroll-triggered reveals, micro-animations, dan celebratory confetti.
3. **Spiciness Simulator & Heat Meter Gimmick**:
   - Pengunjung dapat memilih 4 tingkatan pedas: **Level 1 (Santai Dulu)**, **Level 2 (Nendang Pas)**, **Level 3 (Nampol 56)**, dan **Level Dewa (Juanda Membara)**.
   - Rekomendasi penetral pedas otomatis (Nasi Daun Jeruk + Es Jeruk Segar) dan tombol tantang teman dengan teks share interaktif.
4. **Indikator Toko Real-Time (Live Status)**:
   - Mendeteksi otomatis jam operasional WIB (**18:00 - 02:00 WIB**), menampilkan badge hijau berdenyut saat buka atau penanda jam buka berikutnya.
5. **Katalog Menu & Simulasi Keranjang (Cart)**:
   - Filter kategori: Semua Menu, Sate Taichan, Paket Rame-Rame, Saus Tambahan, Nasi & Lontong, Dessert & Minuman.
   - Informasi porsi (10 tusuk / 30 tusuk), level pedas, dan harga transparan.
6. **WhatsApp Order Generator Otomatis**:
   - Pilihan tipe pesanan (*Dine-In*, *Take Away*, *Delivery*).
   - Pilihan racikan sambal (Dipisah / Dicampur).
   - Menghasilkan format pesan WhatsApp rapi siap kirim ke kasir Taichan 56 Margonda hanya dengan 1 klik!
7. **Instagram Feed Showcase**:
   - Menampilkan profil resmi `@taichan56djoeanda`, tautan langsung, reels preview, dan showcase sajian sate taichan.
8. **Lokasi & Rute Google Maps**:
   - Panduan alamat jelas: Jl. Margonda Raya, persis di samping KFC Margonda.
   - Embed peta interaktif dan tombol penunjuk arah.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 6](https://vite.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Special Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: Plus Jakarta Sans & Outfit (Google Fonts)

## 🚀 Menjalankan Project Secara Lokal

Pastikan Anda telah menginstal [Node.js](https://nodejs.org/) (v18+) dan `pnpm` atau `npm`.

```bash
# 1. Clone repository
git clone https://github.com/dieartco206/taichan.git
cd taichan

# 2. Install dependencies
pnpm install
# atau
npm install

# 3. Jalankan server pengembangan (Dev Server)
pnpm run dev
# atau
npm run dev

# 4. Buka browser di http://localhost:5173
```

---

## 📦 Build untuk Produksi

```bash
pnpm run build
# Hasil build statis siap deploy tersedia di direktori /dist
```
